elmorelab.dll — ограниченная проверка при диагностике Gracia
Уровень: поиск строк; содержательное восстановление внутреннего ABI не выполнялось.

Исследованный файл
<GRACIA_CLIENT>\system\elmorelab.dll (корень клиента Gracia; см. 00_README.txt)

Наблюдение
При поиске ASCII/UTF-16 печатных строк по interface.u, DeleteFile,
CompileUIScripts и Interface. совпадений не получено. Это лишь результат данного
поиска, не доказательство отсутствия соответствующей функциональности: строки
могут формироваться динамически, а вызовы — разрешаться иначе.

Границы исследования
Назначение файла не выводилось только из имени. Не установлена причинная связь
с удалением Interface.u, WebView2 RPC_E_DISCONNECTED либо завершением Chromium.
Экспорты/layout/calling conventions не включены в проверенный профиль.
Файл не патчился и не отключался.

Практический результат диагностики
Удаление Interface объяснено исследованным путём NWindow CheckDependency.
WebView2 Gracia заработал через собственный helper без изменения этой DLL.
Для дальнейшего анализа нужен отдельный PE-профиль и трассировка фактических вызовов;
нынешних данных недостаточно для вывода о внутренней реализации.
