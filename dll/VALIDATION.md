# Проверка примера новой native-функции

Актуальный статус: сборка в Windows, загрузка ExtensionL2.u и все реализованные
native-функции в игре проверены. Scryde исключён: рабочая интеграция не получена,
исследования прекращены. Ниже сохранены подробности отдельных этапов проверки.

## Clear HF: исправление несовместимого Core

Добавлен профиль исходной Core.dll SHA256 0677e909... из Clear_hf.
Дисковый патч сохраняет все 2806 именованных экспортов и исходные секции.
Runtime выбирает подходящий набор RVA для GNatives/GRegisterNative/FFrame::Step.

На Clear_hf проверены обычные PE-импорты к Core у 11 локальных модулей:
с новым патчем отсутствующих символов нет. Со старой установленной Core
выявлены отсутствующие GetCPUCacheLineSize (Engine.dll) и SetVGAInfo (D3DDrv.dll).

В Wine-хосте загружены новая патченная Core и оригинальная Engine.dll Clear_hf.
Также прошли все VM-тесты в ручном и автоматическом режимах на новом Core.
Обновлённый модуль дополнительно проверен на предыдущем Core-профиле.
Подробности и готовая пара файлов — в CLEAR_HF_FIX.md.

- Сгенерированы и скомпилированы 7 функций (4000..4006), 0 ошибок/предупреждений.
- Проверены native-индексы, static/final/native flags, параметры и результаты

## Компиляция UC

`ExtensionL2.u`: **0 ошибок, 0 предупреждений**. Класс ExtensionL2Tests — скриптовый,
функция SaturatingAdd64 — numbered native final с индексом 4000.

Фактические байты вызова из ExampleCall:

```text
6f a0 39 5b 1d ff ff ff 7f 39 5b 26 16
```

Это native 4000 с двумя расширениями int→INT64. Именно этот извлечённый поток
исполнен через FFrame::Step клиентской DLL, результат — **2147483648**.

## Ручная регистрация

- До установки слот 4000 содержит execUndefined.
- При искусственно занятом слоте установка отклонена; чужой указатель сохранён.
- После освобождения слот зарегистрирован; повторная установка успешна.
- Чтение аргументов через Step проверено вложенным вызовом новой функции.
- Пройдены семь арифметических случаев, включая насыщение на обоих пределах.

## Модифицированная копия Core.dll

- Оригинальные секции и экспортные RVA совпадают побайтово с исходной DLL.
- Старые import descriptors сохранены, добавлен ExtensionL2.dll!ExtensionL2Attach.
- Новые секции: .ndcode RX и .nddata RW; checksum проверен.
- PE entry point вызывает оригинальный вход Core, затем установку нового native.
- В режиме patched хост загрузил Core.dll: регистрация выполнилась автоматически.
- Все арифметические случаи, вложенный вызов и настоящий UCC-bytecode прошли
  также в режиме patched.

Исходный клиентский Core.dll в decompilled/client_dll не изменялся.
После этих стендовых проверок подтверждены запуск полного игрового клиента,
загрузка ExtensionL2.u и работа реализованных функций в игре (кроме Scryde).
