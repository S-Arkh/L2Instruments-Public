# История препятствий сборки — текущий Interface собран

Полный результат и команды приведены в ../CLIENT_BUILD.md. Итоговая сборка
завершилась с 0 ошибками и 35 предупреждениями; прежние блокеры сняты.

## Что было найдено и исправлено

1. **Actor Owner: Script=60, C++=64.** Клиентские базовые пакеты не соответствовали
   нативной памяти старых DLL компилятора. Найден UE2 Runtime 2226.19.03 с
   побайтово совпадающими четырьмя бинарниками. Его SDK используется только
   при компиляции; клиент сохраняет собственные Core/Engine/NWindow.

2. **FlashSubsystem и другие native-типы.** Их native-регистрация найдена в
   клиентской Engine.dll. Исследовательские объявления находятся в compat/Engine.
   Они не нужны в итоговом SDK-пути: клиентский Engine не пересобирается на
   старой DLL, вместо этого используется совместимый базовый Engine.u.

3. **FWind/ESortOrder до объявления и constructive.** Добавлена нормализация
   деклараций с сохранением порядка полей. Constructive относится к генерации
   C++ конструкторов native struct и исключается из компиляционной копии,
   которая не используется для пересборки клиентских DLL.

4. **Отсутствующие PCX/TGA.** Из оригинального Engine.u восстановлены 84 текстуры
   с проверкой mip-данных. Они сохранены в ClientReference для исследования;
   финальная сборка использует готовый SDK Engine.u.

5. **UnknownFunction, строки и оборванные функции.** В пакетах оказался сохранён
   ScriptText. Извлечены оригиналы 309 классов Engine, 113 NWindow и 253 Interface.

6. **GPF при Texture.Destroy / Material.ShaderCode.** Подтвердил несовместимость
   клиентского layout Material со старым native Engine. Исправлен выбором
   совместимого SDK, без отключения проверок нативного layout.

7. **Actor.EL2ObjectType и новые EInputKey.** Дополнены только enum-метаданные
   SDK. Старые нативные значения общих клавиш сохранены, текстуры и свойства
   не перемещаются. Изменённый Engine.u — только зависимость компилятора.

8. **Перегрузка `255 - CrimRate`.** Расширение в INT64 получило стоимость 102,
   между byte→int (101) и int→float (103). Потеря точности INT64→float имеет
   стоимость 104. Исправлено также соглашение вызова ConversionCost (__thiscall).

9. **Vehicle.MaxFuel/CurFuel/DriverID.** Добавлены символические IntProperty
   для поиска полей при компиляции. Нативный storage и Children класса Vehicle
   не изменяются. В результате записываются импорты к настоящим полям клиента.

## Актуальный статус проверок

- Сборка в Windows проверена (сохранённые артефакты собраны MinGW-w64).
- Полная загрузка нового Interface.u и все реализованные функции в игре проверены.
- Scryde исключён: рабочая интеграция не получена либо исследования прекращены.
- Полная эквивалентность всех defaultproperties не устанавливается игровым тестом;
  при структурном сравнении проверены исходный текст,
  функции, импорты/экспорты, суперклассы и class flags.
