## Среда

- Компиляция готовых PE32: MinGW-w64 i686, GCC 13-posix.
- Выполнение: локально развёрнутый Wine 9.0 x86, Windows 10 mode.
- Оригинальные MSVCR70.dll / MSVCR71.dll из предоставленного комплекта
  (`WINEDLLOVERRIDES=msvcr70,msvcr71=n`).
- Рабочие копии комплектов: `<TEMP>/ucc64-final-suite/*`, где `<TEMP>` — временный каталог проверки.
- Дистрибутив: `dist/win32`; точные хеши — `BUILDINFO.json`.
- Проверенный `Int64Smoke.u`: SHA256
  `0c5a91818b0a96f7b8d84d85a86beb43dcab7dac6f6abbd10be3bbbccce31cd6`.
- Исходные UCC.exe/Core.dll/Editor.dll и клиентские пакеты не изменены.

Wine на этом окружении некорректно отображал секции клиентской DLL при загрузке
непосредственно с подключённого диска Windows: entry point читался как нули. Для выполнения использована
побайтовая копия на Linux filesystem. Изменений PE-заголовков или кода не делалось.

## Выполнение обработчиков клиентской DLL

`client_native_probe.exe` загрузил предоставленную клиентскую Core.dll и вызвал
её настоящие экспортированные обработчики с минимальным FFrame.
Для строковых тестов использован тестовый FMalloc на Win32 heap: до appInit
в клиентской DLL установлен placeholder allocator.

Пройдены:

- int(-1) -> INT64: знаковое расширение и порядок слов;
- сложение, вычитание, умножение, деление с величинами за пределами 32 бит;
- signed INT64_MAX > INT64_MIN;
- путь генерации больших литералов через primitive cast/string для 5000000000,
  INT64_MIN, INT64_MAX;
- точное обратное преобразование этих значений в строку.
- эквивалентность byte(255), byte(255.0) и int(byte(255)), используемая при
  сравнении инструкций оригинального и пересобранного интерфейса.

Этот стенд проверяет отдельные операции VM. Загрузка целого нового пакета
и выполнение интерфейса в игре подтверждены отдельной игровой проверкой.
