# Журналы регрессии

Файлы `.log` рядом — stdout/stderr реального UCC, запущенного через готовые
артефакты из `dist/win32` в Wine x86. Рабочие каталоги находились в
`<TEMP>/ucc64-final-suite`, где `<TEMP>` — временный каталог проверки.

`positive.log`: успешная сборка Core.u и Int64Smoke.u.
Остальные шесть: ожидаемые отказы компиляции без создания Int64Smoke.u.
Во всех отрицательных случаях код завершения 1, в положительном — 0.

Проверенный положительный пакет сохранён в `dist/win32/Int64Smoke.u`.
Для его содержимого используйте `tools/check_smoke.py`.

`interface-build.log` — отдельный полный успешный прогон клиентского интерфейса:
253 класса, 0 ошибок и 35 предупреждений. Актуальные исходники и SDK находятся
в workspace; отчёт сравнения с оригиналом — workspace/interface-comparison.json.
