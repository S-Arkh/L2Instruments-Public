# Результаты итогового снимка

Статус: итоговый аудит, регрессии и проверка комплектов завершены в описанных
ниже границах.
Полная проверка Interface: 1,215 bool-сравнений, неверной арности нет.
Повторная snapshot-регрессия после
исправления bool-токенов завершена: 20/20 для каждого компилятора.

Portable uExplorer упакован из ревизии
`e5d96be7a75380507b92678ce4207380eada46b9`, исправленные комплекты ucc64 — из
`6543d5ded0cb372020fdaec526769e3e2e3e74b9`. Код первоначальных проверок:
`304e8b4`. Этот отчёт дополняет снимки, не меняя их бинарники.
Методика и команды: [ROUNDTRIP_RELEASE.md](ROUNDTRIP_RELEASE.md).

Snapshot включает 14 строгих roundtrip-наборов, отдельный semantic VM-режим,
проверку Sort profile, 12 Sort-отказов, 45 pointer-отказов, pointer lifecycle и
metadata lifecycle. Десять заранее заданных semantic-результатов проверяются на
исходной и восстановленной сборках, а не выводятся из текущей реализации.

Автономные Python-группы: int64 15 PASS / 21 SKIP, DLL 2 PASS / 8 SKIP,
client tools 8 PASS, launcher 5 PASS. SKIP относятся к отдельным внешним эталонам;
их нельзя прибавлять к PASS или заменять результатами других пакетов.

Аудит в auto-режиме: 6,369 recovered и 1,342 source; в принудительном
bytecode-режиме: 7,711 recovered. Для 15 современных пакетов использован
исторический baseline с совпадающими входными хешами. Для 8 legacy-пакетов
старый и новый экспортёр проверены на одних замороженных входах: установленные
legacy Interface уже не совпадали с историческими файлами. Поэтому прежние
7,716 классов и текущие 7,711 относятся к разным наборам входных данных, а не
к потере пяти классов экспортёром. Оба сравнения сохранены отдельно и дали
0 регрессий; все 23 входных пакета остались неизменными.

Дополнительное сравнение трёх сборок Interface до bool-исправления охватило
по 20,203 функции: пропавших/добавленных функций нет, native ID, flags и
replication offset совпадают. Символические AST (исключены только числовые
`reference`) различались в 26 функциях между MSVC/MinGW и в 41 функции между
MSVC и предыдущей сборкой. Это сохранённые расхождения, не PASS семантической
эквивалентности прежних пакетов. Исправленные MSVC/MinGW-пакеты совпадают
побайтово вне GUID; полный скан проверил 1,215 bool-сравнений без ошибок арности.

## Границы результата

Метаданные сравниваются с предыдущим собранным результатом, когда проверяется
регрессия сборки. Отличия от оригинальных клиентских метаданных остаются
установленной несовместимостью, а не скрытым PASS.

Повторные native-сборки MinGW не побайтово идентичны: PE timestamps/checksum,
preferred image base и связанные debug/COFF-данные различаются. Диагностическая
проверка релокаций подтверждает равенство runtime-секций; она не модифицирует
дистрибутив и не доказывает общую воспроизводимость всех native-сборок.

Установленные клиентские файлы не менялись, новый игровой прогон не проводился.
Прежние modern 25/0/0 остаются доказательством только тех проверенных комплектов.
Legacy-указатели не требуются; репликация отложена и запрещена. Без сервера
авторизация, мир и сетевые сценарии не проверены. Push и PR не выполнялись.
