# uExplorer portable — Windows x64

Распакуйте ZIP целиком в доступный для записи каталог и запустите **Start.cmd**.
Python, Qt, DLL ядра и CLI включены; установка Python не требуется.

Откройте каталог с `.u`, `.utx`, `.usx`, `.ukx` или `.uax`, выберите пакет,
режим над списком объектов и объект. Для экспорта кода выберите каталог экспорта.
Подробнее: руководство пользователя `docs/USER_GUIDE.md`.
Ресурсы доступны только для просмотра: текстуры, аудиоплеер, диагностическая
геометрия, граф материалов, diffuse-текстуры, skinning, опорный скелет,
скелетные/вершинные анимации и структурное сравнение пакетов.
Возможности и ограничения: `docs/RESOURCE_GUI.md`.
Для поддерживаемого профиля Model 133/40 доступно полное структурное чтение
сохранённых полей, включая световые данные; просмотр остаётся read-only и
не подтверждает мировое размещение или игровую коллизию.
Непроверенные формы Model отображаются с предупреждением: предполагаемая
геометрия не считается подтверждённой, а если разбор невозможен, показывается
ограниченный фрагмент сохранённых байтов.
У Model с локальной ссылкой доступен отдельный просмотр сохранённых Polys.
Polys не подменяет геометрию Model автоматически и не подтверждает игровую
коллизию или мировое размещение.
Кадрирование Model использует только отображаемые грани; другие сохранённые
точки не удаляются и не считаются неиспользуемыми игрой.
Для некоторых UV-цепочек с triggered/jitter доступен предупреждающий
статический просмотр сохранённых матриц, а не воспроизведение игровых событий.
При противоречии свойства UV2 и сохранённого shader UV0 показывается только
помеченный диагностический UV0, не подтверждённый игровой поток.
Один ограниченный двухсамплерный Combiner показывает независимые анимированные
UV-преобразования с диагностическими, а не игровыми часами; для StaticMesh
могут выбираться разные проверенные UV-потоки.
Для `VertexColor` можно отдельно показать сохранённые цвета StaticMesh;
игровое освещение при этом не воспроизводится.
Для некоторых UV-модификаторов над Shader показывается только Diffuse.
Другие карты и проходы, освещение и игровые часы не воспроизводятся.
Для одной вложенной цепочки доступны только сохранённые UV-матрицы; их
синхронность и игровая анимация не подтверждены.
В отдельном сложном случае можно увидеть лишь sampler 0, не результат
Diffuse или всего материала; остальные слои и opacity не воспроизводятся.
Такой же изолированный снимок sampler доступен для двух вложенных форм
`TexPanner → Combiner`; другие ветви и их alpha не вычисляются.
Для нескольких `TexPanner → Combiner` GPU отдельно фильтрует две Texture
на общих диагностических UV; Qt raster показывает только первую. Игровая
анимация кадров Texture, освещение и игровые часы не воспроизводятся; точная
композиция с другими материалами отключена.
В этих сложных материалах для одного выбранного sampler можно просматривать
сохранённую цепочку кадров `AnimNext` вручную или с диагностической частотой.
Это не игровые FPS и не подтверждение синхронизации или событий.
Для одного проверенного alpha-modulate Combiner GPU показывает ограниченную
формулу по двум Texture без `mFactor` и игрового освещения; это не полное
воспроизведение материала.
Для одного вложенного `TexRotator → Combiner` доступен только изолированный
sampler 0 с четырьмя сохранёнными матрицами; это не итоговый материал, и их
одновременное состояние не подтверждено.

Настройки находятся в `data/settings.ini`, а не в реестре Windows. Для сброса
закройте программу и удалите этот файл. Пути к игровым каталогам и экспорту
сохраняются абсолютными: после переноса на другой компьютер выберите их заново.
Экспорт записывается в выбранный пользователем каталог.

CLI: `bin/uexplorer_cli.exe` принимает один JSON-запрос через stdin и выдаёт
JSON через stdout. Примеры — в `docs/BUILD_AND_TEST.md`.

Проверка окружения: `Start.cmd --check-runtime`.
При ошибке запуска консоль остаётся открытой. Распаковывайте весь архив:
перенос одного EXE/DLL без остальных каталогов не поддерживается.

Версии компонентов, исходный commit, признак локальных изменений и контрольные
суммы файлов находятся в `BUILDINFO.json`. SHA-256 архива — в `SHA256SUMS.txt`
рядом с ZIP; сравните с `Get-FileHash <архив.zip> -Algorithm SHA256`.
