# uExplorer portable — Windows x64

Распакуйте ZIP целиком в доступный для записи каталог и запустите **Start.cmd**.
Python, Qt, DLL ядра и CLI включены; установка Python не требуется.

Откройте каталог с `.u`, выберите пакет и класс, затем каталог экспорта.
Подробнее: руководство пользователя `docs/USER_GUIDE.md`.

Настройки находятся в `data/settings.ini`, а не в реестре Windows. Для сброса
закройте программу и удалите этот файл. Пути к игровым каталогам и экспорту
сохраняются абсолютными: после переноса на другой компьютер выберите их заново.
Экспорт записывается в выбранный пользователем каталог.

CLI: `bin/uexplorer_cli.exe` принимает один JSON-запрос через stdin и выдаёт
JSON через stdout. Примеры — в `docs/BUILD_AND_TEST.md`.

Проверка окружения: `Start.cmd --check-runtime`.
При ошибке запуска консоль остаётся открытой. Распаковывайте весь архив:
перенос одного EXE/DLL без остальных каталогов не поддерживается.

Версии компонентов, исходный commit, признак локальных изменений и контрольные
суммы файлов находятся в `BUILDINFO.json`. SHA-256 архива — в `SHA256SUMS.txt`
рядом с ZIP; сравните с `Get-FileHash <архив.zip> -Algorithm SHA256`.

Лицензии: `LICENSE`, `THIRD_PARTY_NOTICES.md`, `licenses/`, `runtime/`, `packages/`.
