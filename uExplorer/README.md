# uExplorer

Просмотр Unreal Engine 2 / Lineage II `.u`, извлечение сохранённых исходников
и восстановление UnrealScript из метаданных и байткода. Ядро — C++17,
интерфейс — Python/PySide6. Сборка Visual Studio 2022 x64 проверена.

Запуск и реализованные функции в Windows проверены; результаты работы с
целевыми игровыми пакетами подтверждены в исходном проекте. Scryde не входит
в подтверждённые интеграции.

## Быстрый запуск

Из чистого клона сначала установите зависимости и соберите ядро по
[общей инструкции](../docs/BUILD.md#interface-editor-и-uexplorer-x64).
Затем запустите **`uExplorer\run.cmd`**. DLL и CLI создаются в `bin`;
готовые файлы не включены в Git. Скрипт также поддерживает portable runtime редактора.

`run.cmd` автоматически проверяет окружения в следующем порядке:
1. `uExplorer/.venv`;
2. `interface_editor/.venv`;
3. portable runtime `interface_editor/dist/windows/runtime` с его `packages`;
4. `python` из PATH.

Выбирается первый Python 3.10+, в котором действительно загружаются QtCore,
QtGui и QtWidgets. Непригодные окружения пропускаются. Если подходящего нет,
показываются команды создания `.venv` и установки `requirements.txt`.
Зависимости автоматически не устанавливаются. Разрядность Python по-прежнему
должна совпадать с ядром DLL.

Проверить выбор без открытия окна:

```powershell
.\run.cmd -CheckRuntime
```

Явный параметр `-Python` тоже проверяется, но при ошибке не заменяется другим
интерпретатором. `run.cmd` передаёт параметры в `run.ps1` и возвращает код завершения.

Для отдельного Python (3.10+; разрядность должна совпадать с DLL):

```powershell
python -m pip install -r requirements.txt
.\run.ps1 -Python 'C:\Python312\python.exe'
```

Откройте каталог → выберите `.u` слева → класс посередине → исходник справа.
Укажите каталог экспорта и нажмите «Экспорт выбранных» или «Экспорт всего .u».

## Сборка

Нужны Visual Studio 2022 с компонентом **Desktop development with C++**,
Windows SDK, CMake 3.24+ и Python с установленным `nlohmann_json` в PATH.

```powershell
.\build.ps1
```

Создаёт `build-x64\uExplorer.sln`, собирает Release и устанавливает DLL/CLI
в `bin`. Solution можно открыть и собирать непосредственно в VS2022.

## Поддержка и ограничения

- Профили пакетов: `123/0`, `123/37`, `126/0`, `133/40`.
  Для исследованных Essence/Кореи/Японии добавлены INT64, сортировка массивов
  и метаданные делегатов; [проверки и ограничения](docs/PACKAGE_133_40.md).
- Оболочки: plain, `Lineage2Ver111`, `GamekitData111` (XOR `0xAC`).
- ScriptText извлекается с сохранением исходных байтов.
- При отсутствии пригодного ScriptText работает декомпилятор; сложные функции
  могут содержать диспетчер `__RecoveredPC`.
- `partial` означает неполное восстановление; подробности и доступный AST/raw
  находятся в JSON-отчёте. В частности, делегаты, часть defaults, replication
  и state/latent-конструкций требуют доработки.
- Native-функции разрешаются по метаданным зависимостей; машинный код DLL
  не декомпилируется.

Проверено: Gracia — экспорт и повторная компиляция 239 классов, сравнение
3259 функций и 20009 CFG-блоков, метаданных свойств, enum и наследования.
Это проверка конкретного набора, а не гарантия компиляции любого `.u`.
