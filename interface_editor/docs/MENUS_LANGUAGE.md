# Меню, колесо мыши и локализация

## Расположение команд

```text
Файл / File
  Открыть / Open                       Ctrl+O
  Сохранить / Save                     Ctrl+S
  Сохранить как / Save as              Ctrl+Shift+S
  Открыть JSON / Open JSON
  Экспорт JSON / Export JSON

Опции / Options
  [✓] Синхронная прокрутка свойств / Synchronize property scrolling
  [ ] Изменять значения свойств колёсиком / Change property values with mouse wheel
  Язык / Language
    Русский
    English

Опции окна / Pane options              (отдельно у каждой стороны)
  [ ] Показывать соседей и их ветки / Show siblings and their branches
```

Меню «Файл» расположено в верхней панели после выбора хроник, на месте прежнего
«Открыть». «Опции окна» занимает место прежней галочки под строкой поиска.
Это выпадающие меню с отмечаемыми пунктами, а не постоянно видимые checkbox-виджеты.

## Защита значений от колеса

`app/wheel_guard.py` перехватывает Wheel только у редакторов свойств и их дочерних
контролов (QComboBox/QAbstractSpinBox). Если изменение колёсиком отключено,
событие с исходными delta/phase/device перенаправляется в viewport таблицы.
Исходное событие поглощается, чтобы не применить прокрутку дважды.

Колесо над таблицей продолжает работать, включая общую синхронную прокрутку.
Когда опция включена, событие обрабатывается контролом обычным образом.
Настройка не блокирует ручной выбор пункта или ввод с клавиатуры и не распространяется
на выбор хроник, меню и другие элементы вне таблиц свойств.

## Переключение языка

`app/i18n.py` хранит русско-английские подписи. Смена языка не перезагружает
документ и не пересоздаёт модель дерева; обновляются меню, кнопки, заголовки,
подсказки, статусы и подписи bool. Подключается доступный Qt-перевод стандартных
контролов. Нативные диалоги ОС могут использовать системный язык Windows.

Имена объектов, свойства, enum-идентификаторы и сами данные XDAT не переводятся.
Подробные исключения C++/Python отображаются в исходном диагностическом виде.

## Настройки

Используется пространство QSettings: L2Tools / InterfaceEditor.
Настройки предыдущего имени приложения автоматически переносятся при первом запуске.

- language: ru/en, по умолчанию ru;
- wheel_values: false по умолчанию;
- sync_scroll: прежняя общая настройка;
- panes/left/neighbors и panes/right/neighbors: независимые настройки панелей.

Старые ключи «Левая область/neighbors» и «Правая область/neighbors» читаются
при первом переходе. Новые ключи не зависят от выбранного языка.

## Проверки

```powershell
.venv\Scripts\python.exe -m pytest tests/test_gui.py tests/test_menus_language.py -q
```

Проверены состав меню и shortcut Ctrl+O, отключённое/включённое изменение
реального свойства колёсиком, перенаправление события от числового редактора,
синхронная прокрутка, сохранение данных и истории при смене языка,
перевод заголовков/подсказок/результатов поиска и восстановление настроек.

Снимки интерфейса можно создать локально через `tools/capture_ui.py`.
