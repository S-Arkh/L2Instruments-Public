# Предпросмотр Японии и Кореи

Японские normal/Classic XDAT используют `essence_native.XDAT`. Предпросмотр
доступен для этого общего профиля Essence/Japan; отдельного признака региона
в API документа нет. Корейские normal/Classic используют `korea_native.XDAT`.
Проверка реальных файлов выполнена для обоих регионов.

Поддерживаются Window, Button, Texture, TextBox и ScrollArea на уровне
существующего статического рендерера HF. Базовые свойства и определения этих
пяти контролов в профилях Японии и Кореи совпадают. Используемые поля геометрии, привязок,
текстур, текста и enum совпадают с HF; переназначение полей не требуется.
Учитывается `equalToParentSize`, присутствующее в новом профиле.

## Ограничения

- `ScalableData` применяется по выбранному уровню UI 0–100 к масштабируемому
  поддереву; используются коэффициенты X/Y и FontMapping. Runtime-скрипты и
  полное наследование определений не воспроизводятся. Корень без заданного
  `scalable` не считается автоматически масштабируемым.
- Угол -9999 пропускается. Для Z-поворотов и 180° вокруг X/Y используется
  центр прямоугольника как статическое приближение; другие 3D-оси диагностируются.
- Шрифты приблизительные, Qt использует доступные системные шрифты для Unicode.
- Игровые скрипты, анимация, 3D и динамические состояния не исполняются.
- Другие типы, включая RichListCtrl, отображаются подписанными заглушками.
- Для текстур нужен каталог ресурсов соответствующего клиента,
  для локализованных подписей — его SysString. Без них используются заглушки/`#ID`.

## Проверки

Windows, `test_preview_textures.py` + `test_native_textures_portable.py`:
**23 passed, 2 skipped** (опциональные внешние ресурсы).
Ядро пересобрано на Windows и Linux.

Синтетические проверки проходят через настоящий Document и сериализацию:
пять поддерживаемых типов, Unicode-текст и SysString, привязки, процентные размеры,
размер родителя, три состояния кнопки, сообщения об ограничениях, неизменность
снимка и бинарного документа. GUI проверяет загрузку собственной UTX, вкладки,
обновление выбора, изменение ширины/Undo и экспорт PNG для HF, Gracia, Японии и Кореи.
Отдельный синтетический UTX проверяет native-структуру текстуры `133/40`,
оболочку XOR121 и отказ для неподтверждённой версии `133/41`.

Все четыре реальных XDAT из приватных рабочих копий построили родительский
макет для `Refresh_Btn` во всех трёх состояниях с соответствующими клиентскими UTX.
Нормальные снимки японского normal и корейского Classic просмотрены вручную.
Сериализация после предпросмотра и исходные файлы совпадают побайтно.

В каждом макете загружены `L2UI_CT1.GroupBox.GroupBox_DF`,
`L2UI_CT1.ListCtrl.ListCTRL_DF_Decoration` и соответствующее состояние кнопки:
`L2UI_NewTex.Button.Button29_{DF,Down,Over}` для normal,
`L2UI_NewTex.Button.SimpleBtnBrown_{DF,Down,Over}` для Classic.
Проверенные пакеты имеют версию `133/40`, оболочку XOR121 и размеры примерно
294–490 МиБ. Лимит пакета и бюджет кеша пакетов увеличены до 512 МиБ;
декодированные изображения по-прежнему кешируются отдельно с лимитом 32 МиБ.

SysString не подключался (`#938` ожидаем); RichListCtrl остаётся заглушкой.
Совпадение с игровым внешним видом всех окон не подтверждено.
Клиентские XDAT и снимки остаются вне отслеживаемого содержимого репозитория.

## Дополнение: повороты, масштаб и диагностика

Прежний результат тестов выше относится к первоначальному включению профилей.
Новая реализация проверяется дополнительно в `test_preview_transforms.py`:
пиксели при отражении/повороте, sentinel и начальная ось Z, границы изображения,
неравномерный масштаб, процентные размеры без двойного умножения, выбор размера
шрифта по FontMapping, согласованность metadata/revision, Undo, группы замечаний
и кнопка со списком профилей. GUI-проверки переключают уровень UI отдельно от zoom.

Все четыре реальных файла повторно проверены с ресурсами: у
`ShortcutWndHorizontalArena_1` нет ложных сообщений о повороте, неподдерживаемые
12 ячеек объединены в одну группу. Реальные текстуры с углом 180° строят preview.
В японском Classic InventoryWnd на уровнях 0/100 имеет размер preview
642×490 / 1260×956. Исходные XDAT и сериализация остались побайтно неизменными.
Это проверка статического preview, не игрового рендера.

Нативная семантика sentinel/осей и процентов подтверждена статическим разбором
корейской DLL. Технический документ с хешами, RVA, методикой и оставшимися
вопросами: [NWindow_UI_TRANSFORMS.md](../../InfoOfDll/NWindow_UI_TRANSFORMS.md).

Итоговая Windows-проверка дополнения: `test_preview_textures.py`,
`test_preview_transforms.py`, `test_sysstring_gui.py`, `test_menus_language.py`,
`test_gui.py` — **40 passed, 1 skipped** (опциональная проверка внешних UTX).
Ядро с metadata-снимками пересобрано на Windows и Linux. GUI с реальным
корейским окном проверен отдельно: раскрытие группы и диалог клиентов;
снимки просмотрены локально и не включены в репозиторий.
