# Interface Editor — Windows x64

Запуск: **Start.cmd**. Python и Qt уже включены в эту папку.
Целевая система — Windows 10/11 x64. Переносите всю папку целиком.

1. Выберите версию формата вверху (High Five для HF-клиента).
2. Выберите «Файл → Открыть» и выберите Interface.xdat.
3. Используйте независимые поиск и выбор слева/справа.
4. Для добавления кнопки выберите список children нужного окна → «Добавить».
5. Для переноса копии: объект слева → «Копировать», список справа → «Вставить копию».
6. «Файл → Сохранить» проверяет результат и создаёт резервную копию .bak.

Версия UI 0.3.0:
- «Файл»: открытие/сохранение XDAT и открытие/экспорт JSON.
- «Опции»: синхронная прокрутка и изменение значений колёсиком.
  Изменение колёсиком по умолчанию выключено: вместо правки прокручивается таблица.
- «Опции → Язык»: Русский / English, переключение сразу, без перезапуска.
- «Опции окна» под поиском каждой панели: показ соседей и их веток.
Настройки сохраняются, выбранный язык не изменяет данные XDAT.

Дополнения:
- Общий ползунок справа и «Синхронная прокрутка свойств» — перемещение обеих таблиц.
- «Слева → направо» / «Справа → налево» — открыть выбранный объект на другой стороне.
- «Сравнить» — оранжевым разные значения/типы, красным отсутствующие активные поля.
- «Файл → Экспорт JSON» / «Файл → Открыть JSON» — весь документ, включая несохранённые изменения.
- «Опции окна → Показывать соседей и их ветки» — показать другие children
  рядом с совпадением; сами совпадения выделяются жирным.

В JSON редактируется value. Служебный raw сохраняет исходную кодировку, но
не перекрывает изменённое value. После импорта выберите новый путь сохранения XDAT.
Подробная инструкция находится в docs/COMPARISON_JSON.md основного проекта.

Исправлено сохранение при уже существующем .bak: бэкап готовится во временном
файле и заменяется через Win32 API. Обновлённый модуль загружается после
перезапуска редактора. Несохранённые изменения старой сессии можно предварительно
сохранить через «Сохранить как» в новый файл.

Есть вкладки «Свойства» / «Предпросмотр». Для картинок укажите каталог ресурсов
клиента в «Опции». Предпросмотр статический и пока рассчитан на High Five.
Нет локализованной таблицы SysString: такие подписи обозначаются номерами.

Меню «Текстуры» открывает менеджер собственных PNG/TGA-проектов: новый отдельный
UTX, замена картинок, установка, назначение выбранному элементу и мастер кнопки.
Оригинальные пакеты клиента не используются как выход. Установка собственного
UTX и отображение в целевом игровом клиенте проверены, как и чтение и пиксели.
Действия кнопок реализуются отдельно в UnrealScript.

Доступны 24 пункта версий / 23 схемы формата.
27 эталонов и клиентский HF XDAT прошли побайтное чтение/запись.
Для двух RU/NA-схем Infinite Odyssey нет отдельных эталонов.

Сборка и полный запуск GUI в Windows проверены. Нативное ядро дополнительно
проверено под Wine, GUI и две панели — в Linux/Qt. Все реализованные функции
и результаты редактирования проверены в игре; Scryde в подтверждённые интеграции
не входит.
При ошибке запуска консоль остаётся открытой — её сообщение поможет диагностике.

Исходники и полная документация находятся в каталоге проекта interface_editor.

В версии 0.5.0 добавлено меню «Строки»: чтение/редактирование SysString, новые ID,
языковые таблицы, назначение кнопке и сохранение DAT. Кодеки работают внутри
нативного модуля, внешние редакторы не запускаются. Выбор оболочки и ключей
независим от схемы XDAT. По умолчанию сохраняется исходный совместимый режим.
Оригинальные RSA-ключи без обратного ключа не позволяют записывать изменения;
совместимый профиль записи выбирается явно.

Подключите sysstring-e.dat через «Строки → Редактор строк…» — предпросмотр
будет показывать настоящие подписи. Сохраняйте DAT и XDAT отдельно.
Тестовый DAT создан в examples/sysstring_test основного проекта; запись нашим
кодером ещё требует подтверждения в игре.
