# Статический предпросмотр Gracia Epilogue

Поддерживаются `ct24.XDAT` и ранее поддержанный `ct26.XDAT` (High Five).
Общий рендерер рисует Window, Button, Texture, TextBox и ScrollArea;
остальные контролы отображаются подписанными заглушками.

Адаптер Gracia преобразует только снимок для рисования:

| Поле ct24 | Поле общей модели |
| --- | --- |
| `anchor` | `usePosition` |
| `anchor_parent` | `relativePoint` |
| `anchor_this` | `anchorPoint` |
| `anchor_ctrl` | `relativeTo` |
| `text_color` | `fontColor` |

Значения Alignment (1–9), абсолютные размеры, смещения, текстуры кнопки,
UV/alpha и выравнивание текста совместимы с общей моделью. Процентные размеры
рассчитываются относительно родителя. Поле `_reserved_0` и неизвестные `unk*`
не интерпретируются. В частности, фон Window остаётся стандартной заливкой.
Оригинальные поля, схема и байты XDAT при просмотре не изменяются.

Через **Опции → Каталог ресурсов клиента…** выберите корень клиента Gracia.
Для локализованных подписей подключите его SysString через меню **Строки**.
Шрифты приблизительные; скрипты, анимации и игровые состояния не исполняются.

## Проверки

- Windows: `test_preview_textures.py` и `test_native_textures_portable.py` —
  **15 passed, 2 skipped** (опциональные внешние ресурсы).
- Синтетический ct24: привязка к родителю и соседнему контролу, процентные
  размеры, цвет текста, пять поддерживаемых типов, три состояния кнопки,
  неизменность снимка и бинарного документа.
- GUI для ct24/ct26: переключение вкладок, загрузка собственной UTX,
  обновление выбора, изменение ширины и Undo, экспорт PNG.
- Реальная рабочая копия Gracia: `LoginMenuWnd`, три состояния `btnCredit`,
  загрузка текстур из клиентских UTX; прямоугольник кнопки `(9, 86, 98, 27)`,
  PNG родительского окна `139 × 199`. Нормальный снимок просмотрен вручную.
  Без SysString ожидаемо отображаются `#ID`. Исходные байты XDAT сохранены.

Клиентские файлы и снимки остаются вне отслеживаемого содержимого репозитория.
Это проверка статического макета, не визуальная аттестация всех игровых окон.
