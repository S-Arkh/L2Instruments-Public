# Матрица покрытия

## Дополнение: ограничения указателей

Этап закрыт в согласованных границах. Поддержка указателей для legacy Gracia/HF
не требуется: в проверенных Core отсутствуют native-экспорты PtrProperty.
Реализация репликации указателей отложена; запрет компилятора сохраняется.
Эти два пункта не являются блокерами завершения этапа.

Итог corrected-number-contract прогона: Korean/Japan **25 PASS / 0 FAIL / 0 SKIP**,
Build и хеши всех установленных артефактов совпали. Ненулевые разные адреса,
копирование и очистка копий при сохранности native-владельцев подтверждены.
Новый снимок Japan подтверждает итог; новый снимок Korean не найден, его
результат подтверждён отчётом. Два нажатия подтверждены пользователем; отдельных
первых отчётов для побайтового сравнения нет. История ошибок ниже сохранена.

- Объектный контекст pointer: исправлен размер значения в SDK-компиляторе;
  точный roundtrip/метаданные и SDK VM с ненулевым маркером и null receiver PASS.
- Репликация pointer-bearing struct/array/RPC запрещена рекурсивно, включая
  наследование структур. Все 45 отрицательных случаев PASS. Положительный
  контроль обычной репликации, Object-ссылок и локального pointer в RPC PASS.
- Legacy Gracia/HF: экспорты native PtrProperty отсутствуют после инициализации
  DLL, контроль UIntProperty доступен. Текущие адаптеры не поддерживают указатели;
  клиентский SKIP сохраняется. Наличие класса в SDK не заменяет клиентский ABI.
- Ненулевые адреса modern: добавлена проверка через два native GFxValue-владельца;
  первый клиентский прогон дал 23 PASS / 2 FAIL / 0 SKIP на обоих профилях.
  GetInt вернул 0,0 вместо 73,91. Отчёты привязаны к установленным комплектам.
  Тест исправлен на native AllocGFxValue/DeallocGFxValue вместо bare new;
  затем выполнен повторный клиентский прогон.
  Версия с native-выделением дала 22 PASS / 1 FAIL: ненулевые разные указатели
  подтверждены, чтение payload — нет. В native-коде найдено несоответствие
  SetInt/GetInt (типы 5/3); проверка исправлена на GetFloat для типа 5.
  Исправленный полный прогон подтверждён: 25 PASS / 0 FAIL / 0 SKIP.

## Дополнение этапа 5

- Производственный профиль SDK Sort, roundtrip с метаданными и изоляция кэша: PASS.
- Двенадцать отрицательных Sort-фикстур: PASS, включая optional/coerce,
  использование результата и передачу Sort в out-параметр.
- Десять независимых SDK VM-проверок исходного и восстановленного пакетов: PASS;
  int/bool/float helpers, побочные эффекты получателя, enum, структуры и циклы.
  Различия AST явно записываются; общая эквивалентность не заявляется.
- Пустой/одиночный Sort: Korean/Japan клиентский PASS, включая однократное
  вычисление получателя и отсутствие вызовов comparator. Подтверждённые итоги
  modern: 21 PASS / 0 FAIL / 1 SKIP; legacy: 12 PASS / 0 FAIL / 2 SKIP.
  Все четыре отчёта сверены с Build и хешами установленных комплектов;
  скриншоты подтверждают кнопку и итоги. Два нажатия подтверждены пользователем;
  сохранены только конечные отчёты, побайтовое совпадение двух запусков не проверено.
- Исследование флагов Interface/GFxValue завершено с установленной несовместимостью
  контрактов SDK/клиентов. Проверены save/reload, RF_LoadForClient и скалярный
  lifecycle в SDK; полного совпадения метаданных и клиентского GC не заявляем.
  См. [исследование](../int64/docs/METADATA_LIFECYCLE_RESEARCH.md).

Команды: [семантика и Sort](../uExplorer/tests/SEMANTIC_VALIDATION.md).

Успех компиляции, сохранность метаданных и выполнение в клиенте — разные проверки.
Ниже отражён подтверждённый расширенный набор. Связь изменений с компиляторными,
отрицательными и runtime-проверками приведена в
[итоговом аудите](../docs/ROUNDTRIP_RELEASE.md).

| Возможность | Начальный клиентский набор | Следующая проверка |
|---|---|---|
| Native INT64, арифметика, строковое представление | Все четыре PASS, включая отрицательные значения и насыщение на обеих границах | Остальные операторы и отрицательные компиляторные фикстуры |
| Явное enum → INT64, byte → enum | Все четыре PASS | Полное покрытие допустимых и запрещённых преобразований компиляторными фикстурами |
| Optional-массив: пропуск и передача аргумента | Все четыре PASS | Отдельно сохранность флагов дескриптора |
| Квалифицированные структуры | Runtime-структура с enum-полем PASS на четырёх | Зависимости между классами и порядком объявления |
| Enum-объект | Runtime-разрешение полного имени PASS на четырёх | Отрицательные компиляторные случаи |
| Sort: порядок, обратный порядок, дубликаты, делегат, получатель | Japan/Korean PASS; legacy SKIP | Пустой/одиночный массив и производственная совместимость формата |
| UTF-8 файл, native FString | Чтение записанного отчёта PASS на четырёх | Расширенные строковые случаи; native-проверки ошибок сохраняются |
| Лексические области enum/аргументов | Компиляторные фикстуры | Включение в единый финальный аудит |
| Зависимые структуры, context helpers, PC-dispatch | Экспорт и сборка реальных пакетов | Целевые семантические и metadata-проверки |
| UTF-16 staging | Полные сборки четырёх профилей | Финальный аудит Unicode-исходников |
| `instanced`, editable/category | Отдельные metadata-проверки | Финальная сверка исходного и повторно загруженного пакета |
| Восстановленные EV-имена | Генераторные проверки | Неоднозначные/вычисляемые значения остаются числовыми |
| Указатели | Modern: ненулевые разные native-адреса, locals/value/out/return, сравнение и очистка копий PASS; итог 25/0/0 | Legacy не требуется; репликация отложена, рекурсивный запрет проверен; общее native-владение вне проверенного набора не заявляется |
| Кнопка, файл отчёта, экранный итог, повторное нажатие | Все четыре проверены | Клиентский тест отказа записи исключён по согласованному решению |
| Привязка отчёта к артефактам | Проверка файлов на диске прошла на четырёх | Не является аттестацией модулей уже запущенного процесса |

Расширение из шести проверок прошло на всех четырёх клиентах: 12 PASS/0 FAIL/2 SKIP
для legacy и 16 PASS/0 FAIL/1 SKIP для modern. Проверены хеши установленных
артефактов, Build и счётчики отчётов; снимки подтверждают видимый итог и кнопку.
Это подтверждает отрицательный INT64, насыщение на обеих границах, переданный
optional-массив, квалифицированную структуру с enum-полем и enum-объект.
Пользователь подтвердил два нажатия на каждом клиенте. Повторные отчёты прошли
проверку хешей артефактов, Build и счётчиков и совпали с первыми побайтово:
счётчики не накапливаются, отчёт не дописывается к предыдущему. SKIP не включается в PASS.

## Связь с проверками вне клиента

Этап 4: pointer-фикстура прошла экспорт/повторную компиляцию, независимую проверку
метаданных функций и fresh-process lifecycle с исполнением через `ProcessEvent`.
Пройдены 37 отрицательных случаев, шесть регрессионных наборов (`expressions`,
`int64_enums`, `optional_arrays`, `enum_collisions`, `metadata`, `array_sort`),
семь CTests экспортера и тест INT64 semantics. Новые комплекты собраны на всех
четырёх профилях. Это не переносит прежний клиентский PASS на новые сборки.

Подтверждённый modern-итог нового набора — 19 PASS/0 FAIL/1 SKIP:
SKIP относится к ненулевым клиентским указателям. Legacy сохраняет 12 PASS/0 FAIL/
2 SKIP. Проверены все четыре установленных артефакта и Build каждого отчёта.
Снимки Japan/Korean/Gracia подтверждают видимый итог; High Five проверен по отчёту.
Пользователь подтвердил два нажатия на профиль. Сохранён только отчёт после них,
поэтому совпадение двух отдельных отчётов для этого этапа не заявляется.

| Область | Проверяемые материалы |
|---|---|
| Enum-объекты, Unicode-литералы, контекстные константы | `uExplorer/tests/expressions/ExpressionProbe.uc` |
| Optional-массивы и запрещённые объявления | `uExplorer/tests/optional_arrays/`, `optional_arrays_unsupported/` |
| Явные и запрещённые неявные enum → INT64 | `uExplorer/tests/int64_enums/`, `int64_enums_unsupported/` |
| Лексическое разрешение одинаковых enum-имён | `uExplorer/tests/enum_collisions/` |
| Метаданные, editable/category, вложенные типы | `uExplorer/tests/metadata/`, `test_metadata.cpp`, `inspect_metadata.cpp` |
| Клиентские enum-зависимости | `uExplorer/tests/client_enums/`, `client_enums_legacy/` |
| События и имена EV | `uExplorer/tests/event_switch/`, `compile_event_switch.py` |
| Sort и неподдерживаемые формы | `uExplorer/tests/array_sort/`, `array_sort_unsupported/` |
| Привязка отчёта, неизвестный профиль, отсутствующие зависимости, подмена артефакта | `test_interfaces/tests/` |

Наличие фикстуры не заменяет результат запуска. Полный аудит на едином финальном
снимке выполняется на этапе регрессий; текущие целевые прогоны фиксируются отдельно.

Целевой прогон этапа 3 завершён успешно для пяти наборов: `expressions`,
`optional_arrays`, `int64_enums`, `enum_collisions`, `metadata`. Каждый прошёл
`compile_generation.py` с библиотекой экспортера; для совпадающих enum-имён включён
`--scoped-enum-casts`. Эти результаты дополняют клиентские проверки и не заменяют
финальный аудит всех профилей и отрицательных фикстур.
