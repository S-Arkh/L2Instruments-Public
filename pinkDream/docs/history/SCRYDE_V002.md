## Установка поверх работающей v001

Закройте игру и лаунчер. PowerShell из каталога pinkDream:

```powershell
$py = '..\interface_editor\dist\windows\runtime\python.exe'
$ClientRoot = Read-Host 'Полный путь к корню Scryde, содержащему SysTextures'
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v002 --check
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v002 --backup backups\scryde-trial-v002
```

Эта версия принимает три пакета v001 и два исходных пакета L2UI/patch.
Она не предназначена для прямой установки на полностью исходный клиент.
Все пять исходных для обновления файлов сохраняются перед заменой.

Откат к состоянию до обновления (работающей v001):

```powershell
& $py tools\install.py rollback --backup backups\scryde-trial-v002
```

## Повторная сборка

Нужен клиент с установленной v001 и исходными L2UI/patch:

```sh
python tools/build_trial.py --profile scryde --revision trial-v003 --base-bundle builds/scryde/trial-v001
```

Генератор сверяет базовую сборку и цепочку её предшественников с исходной
инвентаризацией, а пакеты и наследуемые изображения — по хешам. Новые исходники находятся в
`assets/source/scryde/trial-v002`, новые PNG/TGA — в `assets/generated/scryde/trial-v002`.
Manifest ссылается также на 45 сохранённых ресурсов v001: для переиспользования
библиотеки храните обе версии.
