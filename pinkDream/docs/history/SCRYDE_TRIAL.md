## Установка Windows

Закройте игру и лаунчер. В PowerShell перейдите в каталог pinkDream.
Команды используют имеющийся Python из соседнего interface_editor, без зависимостей:

```powershell
$py = '..\interface_editor\dist\windows\runtime\python.exe'
$ClientRoot = Read-Host 'Полный путь к корню Scryde, содержащему SysTextures'
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v001 --check
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v001 --backup backups\scryde-trial-v001
```

Указывайте корень клиента, содержащий SysTextures. `--check` ничего не записывает.
Установка принимает только исходные хеши проверенной версии клиента; оригиналы
всех трёх пакетов сохраняются до первой замены. Каталог backup должен быть новым.
После установки запустите игру обычным способом и проверьте окна и кнопки.
Зафиксируйте, принимает ли клиент пакеты, и сделайте скриншот интерфейса.

## Откат

При закрытой игре и лаунчере:

```powershell
& $py tools\install.py rollback --backup backups\scryde-trial-v001
```

Откат восстанавливает оригиналы по журналу. Если лаунчер обновил пакет или файл
изменён вручную, несовпадение хеша остановит откат до записи: резервная копия
остаётся в backup. Журнал позволяет откатить и частично завершённую установку.
