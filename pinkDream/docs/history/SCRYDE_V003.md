## Обновление с v002

Установленные пять пакетов проверены: соответствуют v002.
Закройте игру и лаунчер. PowerShell из каталога pinkDream:

```powershell
$py = '..\interface_editor\dist\windows\runtime\python.exe'
$ClientRoot = Read-Host 'Полный путь к корню Scryde, содержащему SysTextures'
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v003 --check
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\trial-v003 --backup backups\scryde-trial-v003
```

Откат к v002:

```powershell
& $py tools\install.py rollback --backup backups\scryde-trial-v003
```

Этот комплект предназначен для обновления с v002, не напрямую с v001.

## Повторная сборка

```sh
python tools/build_trial.py --profile scryde --revision trial-v004 --base-bundle builds/scryde/trial-v002
```

Команда выше использует клиент с v002. Генератор проверяет цепочку manifests
вплоть до хешей оригинальной инвентаризации. Храните v001/v002/v003 вместе:
новые manifests переиспользуют сохранённые изображения предыдущих версий.
