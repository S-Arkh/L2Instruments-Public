# Очистка проекта

Удалены проверенные UTX-дубликаты trial-v001…v004 и прежние loose-каталоги
изображений/предпросмотров этих trial-версий. Всего убрано из старых путей
1173918027 байт (около 1,09 GiB); часть небольших изображений перенесена в store.

До удаления:

1. Проверена независимая библиотека standard-ui-v001 и все её CAS-объекты.
2. UTX сверены с хешами manifests; неизвестные/изменённые файлы не удаляются.
3. 1373 файла изображений, manifests и snapshots сохранены по хешам.
4. Записан восстановительный индекс `assets/archives/legacy-trials-v1.json`.
5. Все архивные объекты перечитаны и проверены перед удалением каталогов.

Прерванная по времени очистка завершена через `cleanup_legacy.py --resume`
с повторной проверкой оставшихся файлов. Нераспознанных файлов в trial-каталогах
не обнаружено. Старые бинарные комплекты v001…v003 не архивируются повторно;
layout v004 уже хранится в независимой библиотеке по хешам.

Сохранены:

- все стандартные исходники и старые сгенерированные изображения в CAS;
- актуальные темы и их снимки, исходная библиотека, концепты;
- Christmas v001 как установленная предыдущая тема;
- найденный `builds/scryde/christmas/v001/SysTextures.zip`;
- исторические подтверждения работы и отчёты;
- backups и рабочие ручные правки, если появятся.

Архивные записи содержат `original_path` и `object` (путь, SHA-256, размер).
Для восстановления изображений в новый каталог:

```sh
python tools/library.py restore-archive --archive assets/archives/legacy-trials-v1.json --out work/restored-trial --pattern "assets/generated/scryde/trial-v001/*.png"
```

Содержимое также можно получить через `asset_store.read(record['object'])`.
Store автоматически не очищается: это защищает будущие
переиспользования и архив ручных вариантов.

Проверки новых Christmas v002/Halloween v001 выполняются уже независимо от
удалённых trial-каталогов. Подробности архитектуры: [ADDING_THEMES.md](ADDING_THEMES.md).
