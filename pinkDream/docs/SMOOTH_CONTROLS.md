# Исправление растягиваемых элементов сезонных тем

Основание — игровые скриншоты Scryde `Shot00097.jpg` (Christmas)
и `Shot00099.jpg` (Halloween). На перетягиваемом крае панели умений,
полосах прокрутки инвентаря и других узких элементах декор повторялся или
растягивался в обрывки. Причина в назначении рисунка маленьким slice/tile-ресурсам.

## Новые версии

- Christmas **v003**: растягиваемые элементы в спокойной зелёной гамме.
- Halloween **v002**: те же элементы в однотонной сливовой гамме.

Сохраняются исходные рельеф, прозрачность, формы и состояния. Новый рисунок
на таких ресурсах не рисуется. Стрелки прокрутки остаются читаемыми.
Полосы, гирлянды, тыквы и паутина остаются на крупных декоративных заголовках.

Новые роли `stretch` и `plain-control` распознаются раньше общего правила
`frame`/`button`, включая маленькие горизонтальные и вертикальные сегменты
рамок, которыми клиент оформляет перетягиваемую панель умений.

Сравнение повторения/растягивания до и после:
`assets/previews/seasonal-scaling-fix.png`. Горизонтальный тайл на листе
повёрнут на 90° после повторения для удобства сравнения с вертикальными полосами.

## Проверено

Сборка в Windows и работа исправленных тем в Scryde проверены в игре,
включая растягивание и повторение рамок и ползунков.

В каждой теме изменено 74 ресурса (58 растягиваемых частей и 16 стрелок/кнопок
прокрутки); остальные 372 готовых изображения побайтово совпадают с предыдущей
версией. Проверены все 492 mip-уровня, alpha, пакеты и установка/откат на копии.
11 unit-тестов прошли. Windows `--check` установленной Halloween v001 для обновления
на v002 прошёл. Регрессия записана в `profiles/scryde/scaling-fix-regression.json`.

## Установка

Файлы для замены:

```text
builds/scryde/christmas/v003/SysTextures
builds/scryde/halloween/v002/SysTextures
```

Установщик с резервной копией, при закрытой игре/лаунчере:

```powershell
$py = '..\interface_editor\dist\windows\runtime\python.exe'
$ClientRoot = Read-Host 'Полный путь к корню Scryde, содержащему SysTextures'
# Если установлена Christmas v002:
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\christmas\v003 --from-bundle builds\scryde\christmas\v002 --backup backups\christmas-smooth-v003
# Если установлена Halloween v001:
& $py tools\install.py install --client $ClientRoot --bundle builds\scryde\halloween\v002 --from-bundle builds\scryde\halloween\v001 --backup backups\halloween-smooth-v002
```

Для перехода между темами в `--from-bundle` указывается фактически установленная
тема. `--check` проверяет применимость без записи. Откат —
`tools/install.py rollback --backup <каталог резервной копии>`.

После установки проверить панель умений в горизонтальном/вертикальном виде,
изменение размеров окон и чата, бегунки инвентаря и настройки. Новый игровой тест
нужен для подтверждения исправления; сам факт офлайн-проверки его не заменяет.
