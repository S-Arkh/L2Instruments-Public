# Профили и сборка

Система тем v2 с импортом изображений, библиотекой по хешам и рождественской темой:
[THEMES.md](THEMES.md). Ниже — описание прежнего trial-конвейера, сохранённого
для воспроизводимости ранних сборок.

## Два вида генерации

`generator/generate.py` создаёт независимые концепты по theme.json.
`tools/build_trial.py` генерирует розовые варианты реальных ресурсов по
`profiles/scryde/selection.json`. Первая пробная подборка содержит 45 фонов
окон и поверхностей кнопок, без надписей. Полные mappings хранятся в manifest сборки.

## Формат и упаковка

`tools/inventory.py` читает таблицы пакетов и оболочки Lineage2Ver/GamekitData 111/121.
`tools/texture.py` читает tagged properties, Lineage material data и встроенные
mip-уровни UE2 123/37 и 125/38. Форматы: BGRA8, DXT1, DXT3, DXT5.
Обнаруженный неподдерживаемый формат или хвост сериализации останавливает обработку.
Описание Lineage material serialization сверено с UEViewer:
https://github.com/gildor2/UEViewer/blob/master/Unreal/UnrealMaterial/UnMaterial2.h

BGRA8 перекрашивается по яркости с сохранением alpha. В DXT меняются RGB565
цветовые endpoints, сохраняются индексы и alpha-блоки; для DXT1 сохраняется
режим прозрачности. Это ограниченный упаковщик цветовых вариантов, не универсальный
импортёр произвольных изображений. Сохранённые PNG/TGA декодированы из результата
упаковки и точно соответствуют пикселям устанавливаемого пакета.

Патчер заменяет байты строго внутри выбранных mip payloads; длина пакета,
таблицы имён/экспортов, смещения, материал, размеры и остальные ресурсы неизменны.
Исходная XOR-оболочка сохраняется. Пакет повторно читается после записи.
Alpha сравнивается попиксельно для каждого mip. Смещения и геометрия изображений
не меняются; семантическая разметка атласов пока не исследована.

## Воспроизводимость и версии

Сборка сверяет пакеты с хешами inventory-20261029.json. После обновления клиента
нужна новая инвентаризация и повторная проверка выбора ресурсов. Существующие
версии не перезаписываются. Снимки скриптов и selection лежат рядом с изображениями.
Установщик использует только manifest и готовые UTX, Pillow для него не нужен.

## Дальнейшая работа

1. Игровой тест trial-v001: допуск пакетов, вид окон и кнопок.
2. По скриншотам определить дополнительные используемые ресурсы Scryde.
3. Расширить подборку, настроить отдельные оттенки фонов/кнопок/акцентов.
4. Добавить импорт ручных PNG/TGA с проверкой alpha и mipmaps.
5. Подготовить и проверить собственные mappings HF/Gracia.

`game_tested: false` остаётся до подтверждения конкретного комплекта в игре.
