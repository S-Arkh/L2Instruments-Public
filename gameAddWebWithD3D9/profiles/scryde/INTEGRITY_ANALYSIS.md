# Начальный анализ проверки целостности

Статус: исследование остановлено. Обход не реализован, бинарные патчи не применялись.
[Общая сводка и состояние интерфейса](README.md).

## Проверка ссылок и структуры PE

ImageBase загрузчика — 0x400000. Для четырёх перечисленных ниже строк вычислены
VA 0x725678, 0x7264c8, 0x726520 и 0x726a60. Поиск их точных 32-битных
little-endian значений в файле не выявил ссылок. Это не доказывает, что строки
не используются: адреса могут вычисляться, преобразовываться или восстанавливаться
при запуске. Ветка отказа по этим данным не найдена.

Точки входа и секции:

- ScrydeGame.exe: entry RVA 0x1fa6be9 в .aaz2; присутствуют .aaz0/.aaz1/.aaz2.
- clmods.dll: entry RVA 0x15bb2d5 в .aaz2; .text/.rdata/.data имеют нулевой
  размер файловых данных. Основной файловый массив находится в .aaz2.
- ScrydeRadio.dll: entry RVA 0x600021 в .UPX2; .text/.rdata/.data также без
  файловых данных. Имена секций сами по себе не устанавливают конкретный упаковщик.
- ScrydeGame.bin: entry RVA 0x17a86 в .text.

Эта структура ограничивает статический анализ исходной логики DLL на диске:
обычный поиск строк и прямых ссылок не даёт проверенную функцию контроля UI.
Патчей к исполняемым файлам не применялось. Запуск изменённого клиента не достигнут.

Статическое чтение ScrydeGame.exe из тестовой копии; бинарники не изменялись.

Найдены UTF-16 диагностические строки (смещения в файле, не RVA):

- 0x324078: `Network error: client files doesn't correspond to server files`
- 0x324ec8: `PreStart1 error: Games files are corrupt`
- 0x324f20: `PreStart1 error: Нарушена целостность файлов игры`
- 0x325460: `PostStart3 error: game was unexpectedly terminated, please check your game files`

Они показывают наличие нескольких сообщений, связанных с согласованием файлов
и стадиями запуска, но не доказывают, какое из них связано с наблюдавшимся
окном отказа Interface.u/XDAT. Ссылки из исполняемого кода пока не установлены.
Строка Network error сама по себе не доказывает серверное решение о хеше.

В импортах загрузчика есть CryptCreateHash, CryptHashData, CryptGetHashParam,
CryptDecrypt и другие криптографические функции. Их использование для проверки
именно интерфейса не установлено. Строки SHA/MD5 и сообщения libcurl/OpenSSL
не следует принимать за найденную проверку UI.

Поиск имён files.xml/failhash/checkhash и буквальных Interface.u/Interface.xdat
в рассмотренных бинарниках не выявил открытого манифеста или выключателя проверки.
Прямой поиск не исключает упакованных, вычисляемых или получаемых по сети данных.

Итог: механизм решения об отказе ещё не локализован; способ запуска изменённого
клиента не реализован. Удаление отдельных сообщений или произвольная подмена
результата криптографической функции не обоснованы полученными данными.
